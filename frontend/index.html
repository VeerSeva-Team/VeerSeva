About VeerSeva

VeerSeva is an academic Defence Welfare Management System prototype. It demonstrates how a web interface, Python Flask backend and MySQL database can work together to display welfare schemes and record application submissions.

The scheme information is sample project data and should not be treated as official government guidance.
