Relational Database Core

DBMS Schema & Integrity

Architected with 8 relational tables, stored procedures (CheckEligibility, LogAuditAction), indexed queries, and cascade triggers.

1. users PK: user_id

Manages beneficiary credentials, service numbers, and role permissions.

• UNIQUE (email) • INDEX (user_type)
2. schemes PK: scheme_id

Central catalog of active defence welfare schemes, benefits, and deadlines.

• INDEX (category, status) • Active flag filtering
3. eligibility_rules FK: scheme_id

Parametric rules evaluated by the CheckEligibility stored procedure.

• Age ceilings (min_age, max_age) • Income limits & branch rules
4. applications PK: application_id

Primary application registry linking beneficiaries to selected schemes.

• FK user_id, scheme_id • Status: SUBMITTED, APPROVED
5. documents FK: application_id

Tracks verified file attachments: Service IDs, PPOs, and medical bills.

• CASCADE deletion on app purge • Document type validation
6. application_status Trigger Driven

Historical timeline logs for application stage transitions and remarks.

• Automatic trigger execution • Timestamped audit trail
7. notifications FK: user_id

Alerts dispatched to veterans regarding document verification & grant disbursals.

• Boolean is_read tracking • Priority messaging
8. audit_logs Security Core

Immutable transaction history logging user inserts, queries, and updates.

• LogAuditAction Procedure • Table & record ID tracking
