# VeerSeva – Defence Welfare Management System

## Phase 2 Project

VeerSeva is an academic Defence Welfare Management System developed by integrating concepts of:

- Database Management Systems (DBMS)
- Operating Systems (OS)
- Backend Development
- Frontend Development

## Objective

The system provides a centralized platform to manage defence welfare schemes, user information, eligibility, applications, documents and application status.

## Technology Stack

### Frontend
- HTML
- CSS
- JavaScript
- Bootstrap

### Backend
- Python
- Flask

### Database
- MySQL

### Operating System Module
- Python-based simulation

## DBMS Modules

The database module will manage:

- Users
- Welfare Schemes
- Eligibility Rules
- Applications
- Documents
- Application Status
- Notifications
- Audit Logs

## OS Modules

The OS module will demonstrate:

- Process Management
- CPU Scheduling
- FCFS
- SJF
- Priority Scheduling
- Round Robin
- Memory Management
- Page Replacement
- Disk Scheduling
- Deadlock Handling

## Project Architecture

Frontend → Flask Backend → MySQL Database

                     ↓

              OS Simulation Module

## Current Phase

Phase 2 focuses on implementing the database, backend, frontend and operating-system simulation modules and integrating them into a functional academic prototype.

## Disclaimer

This project is an academic prototype developed for educational purposes. It is not an official government welfare portal. The welfare schemes and user information used in the system are sample/academic data.
